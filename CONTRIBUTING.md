# Правила команды

Мы работаем по GitHub Flow.

1. Каждая задача — своя ветка от свежего `main`: `feature/…`, `fix/…` или `docs/…`.
2. Готовую ветку отправляй на GitHub и открывай Pull Request в `main`.
3. Pull Request сливают только после одобрения ревьюера.
4. Замечания ревьюера исправляй в той же ветке — Pull Request обновится сам.
5. После слияния ветку удаляют.
