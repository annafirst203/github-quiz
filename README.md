# GitHub-квиз

Консольная викторина по Git и GitHub: пять вопросов по лекции, ответ — номер варианта, в конце — итог в процентах.

## Как запустить

Нужен .NET 8 или новее.

```bash
git clone https://github.com/GlebKievsky/github-quiz-demo.git
cd github-quiz-demo
dotnet run
```

## Файлы проекта

| Файл | Что внутри |
|------|------------|
| `Program.cs` | задаёт вопросы по очереди, проверяет ответы, считает итог |
| `Question.cs` | модель вопроса: текст, варианты, номер правильного варианта |
| `Questions.cs` | список всех вопросов викторины |

> [!TIP]
> Хочешь добавить свой вопрос? Скопируй блок `new(...)` в `Questions.cs` и поставь его в конец списка.
